# 中国古代科技史 · 数字化交互网页

## 📖 项目简介

这是一个展示中国古代科技成就的交互式网页，覆盖从上古神话时代到清末（西学东渐）的中国科技发展历程。网页采用传统国风设计风格，结合现代Web技术（CSS动画、Three.js 3D特效），适合作为历史文化类课程期末作业展示。

## 🚀 使用方式

### 方式一：直接打开（推荐）

1. 双击 `index.html` 即可在浏览器中打开
2. 需要网络连接（用于加载 Three.js CDN）
3. 建议使用 Chrome、Edge、Firefox 等现代浏览器

### 方式二：本地服务器

```bash
# 使用 Python 3
python -m http.server 8080

# 或使用 Node.js
npx serve .

# 然后访问 http://localhost:8080
```

### 离线使用

如果需要在完全离线环境下运行，可以：

1. 下载 Three.js 库文件放到同目录下
2. 修改 `index.html` 中 `<script src="..."> ` 指向本地 Three.js 文件

## 🎨 设计特色

- **配色**：宣纸米色底、朱砂红、墨色、金色、青绿山水色
- **纹理**：CSS 生成的仿古宣纸纹理背景
- **动画**：水墨晕染进入、烟雾飘动、金色流光、印章盖章、脉冲时间轴
- **3D**：Three.js 星空粒子（二十八宿）、环形浑天仪装饰
- **字体**：优先使用系统楷体/宋体等中文字体

## 📋 内容覆盖

### 时期（7个）
- 上古至夏商周（神话时代、青铜文明）
- 春秋战国（百家争鸣、科学萌芽）
- 秦汉（大一统科技）
- 三国两晋南北朝（数学与农业高峰）
- 隋唐（盛世科技）
- 宋元（科技巅峰）
- 明清（集成与西学东渐）

### 领域（6类）
- ⭐ 天文学（7项）
- 🔢 数学（5项）
- 🌾 农业与水利（4项）
- 💊 医学（5项）
- 🔥 四大发明（5项）
- 🏗️ 其他重大发明（5项）

### 交互功能
- 横向时间轴（点击切换朝代）
- 科技分类筛选按钮
- 点击卡片展开详细信息（含史料来源）
- "反驳偏见"专区（回应常见误解）
- 墨点粒子跟随鼠标
- 键盘左右方向键切换分类
- ESC 关闭弹窗

## 🔧 CDN 说明

Three.js 通过 bootcdn 加载：
```
https://cdn.bootcdn.net/ajax/libs/three.js/r128/three.min.js
```

备选 CDN（可自行替换）：
- unpkg: `https://unpkg.com/three@0.157.0/build/three.min.js`
- jsdelivr: `https://cdn.jsdelivr.net/npm/three@0.157.0/build/three.min.js`

## ⚠️ 注意事项

- 所有科技成就描述均基于真实史料，年代和出处经过考证
- 每个科技项目介绍为 200-500 字，包含发明者、原理、历史价值、史料来源
- 页面为单文件，所有资源内嵌，方便提交和分享
- 建议在 1920×1080 或更高分辨率下查看以获得最佳效果
