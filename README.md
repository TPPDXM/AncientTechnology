# 华夏之光 · 中国古代科技史

> 精选三十一项重大科技成就 · 跨越五千年的智慧结晶

## 📖 简介

交互式中国古代科技成就展示网页，覆盖从上古至明清七段历史时期、六大科技领域，共计 **31 项**重大发明。国风设计结合 Three.js 3D 背景、蛇形时间轴、实时搜索筛选等现代 Web 技术，适合历史文化展示与教学场景。

## 🚀 使用

```bash
# 直接双击打开
index.html

# 或本地服务器
python -m http.server 8080
```

需要网络加载 Three.js CDN。Chrome / Edge / Firefox 等现代浏览器均可。

## 🖱️ 交互功能

- **🔍 实时搜索** — 输入即搜，匹配名称/人物/朝代/描述，`Ctrl+K` 快速聚焦
- **📜 蛇形时间轴** — 点击朝代节点查看该时期发明概览
- **🏷️ 分类筛选** — 六大领域按钮，`← →` 方向键切换
- **🃏 卡片详情** — 点击弹出完整介绍 + 史料来源，ESC 关闭
- **💬 反驳偏见** — "正本清源"专区，回应常见误解
- **⬆️ 返回顶部** — 滚动超过 500px 自动出现
